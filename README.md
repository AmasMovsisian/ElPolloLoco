# 🕹️ El Pollo Loco

A browser-based **Jump, Run & Throw** game built with **HTML, CSS, and JavaScript** using an **Object-Oriented Programming (OOP)** approach.

Help **Pepe** collect coins and Tabasco salsa bottles while fighting against crazy chickens and defeating the final boss. Jump, run, avoid enemies, and use your salsa bottles to survive the adventure!

## 🚀 Features

- Object-Oriented JavaScript architecture
- Smooth character movement and animations
- Collectible coins and Tabasco salsa bottles
- Different enemy types including a final boss
- Bottle throwing mechanics with splash animations
- Collision detection system
- Health, coin, bottle, and boss status bars
- Sound effects and background music with toggle option
- Dynamic game world with animated objects

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Object-Oriented Programming (OOP)
- Canvas API

## 🎮 How to Play

Control **Pepe** and help him defeat the crazy chickens!

### Controls

- **← or A** – Move Left
- **→ or D** – Move Right
- **↑, W, or Space** – Jump
- **F** – Throw Bottle

### Important

⚠️ The next bottle throw is only possible after **2 seconds**.

Collect coins and Tabasco salsa bottles, avoid enemies, and use your bottles wisely to defeat the final boss!
